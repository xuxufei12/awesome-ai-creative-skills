## Collected text / 收录正文

````text
先有文本,再谈视觉。
工具:豆包 / Kimi / DeepSeek
要点:一集控制在500‒800字,明确钩子、冲突、爽点、结尾钩子。让大模型输出结构化内容(场景、动作、对白、情绪),方便
后面拆分镜。

把文字转成镜头语言。
一集60‒90秒常见12‒14个镜头,每镜3‒6秒。
前3秒必须出冲突/钩子。
工具辅助:剧云、即梦AI、知漫剧等一站式平台可自动拆分镜。
󾠰 角色设定(真正的核心重点)
这是整条流水线成败的分水岭。角色立不住,后面再漂亮的动态也容易变脸。
必须做:角色三视图(正/侧/背)+ 固定特征描述(脸型、眼型、发型、服装、配饰)。
常用锁定方式:
即梦AI的角色参考 / Seedance系列(多模态参考,一致性较强)
可灵AI的主体库(@角色名调用)
进阶:Midjourney --cref、IP-Adapter / LoRA
原则:先锁死角色资产,再批量出图/出视频,而不是每张图都重新抽卡。
Sohu

把分镜变成静态画面。
主流工具:即梦AI(中文友好、角色参考强)、Flux / Midjourney(画质上限高)。
提示词固定结构:主体描述 + 环境 + 风格 + 镜头语言 + 光影。同一角色必须复用同一套特征词 + 参考图。

让静态关键帧动起来。
国内高频选择:即梦AI(图生视频衔接顺、角色一致性好)、可灵AI(动态自然、物理感强)。
技巧:优先用首帧/首尾帧控制,运动幅度宁小勿大,复杂动作单独处理。每段3‒5秒最稳。

声音是第二灵魂。
配音:剪映AI配音(零门槛、直接对齐时间轴)、豆包TTS(情绪更细)。
BGM:Suno或免费素材。
后期:剪映完成字幕、转场、音量闪避(配音出现时自动压低BGM)。

检查角色一致性、口型、节奏、合规标识 → 导出9:16竖屏 → 发布。
````
