````text
【A 创作:3步】
1. 先对齐:用提示词让Claude先问你5个短问题,锁定目标、语气和"完成"的标准,再列出每一拍:说什么、屏幕上放什么。等
你点头再开工,避免白烧token。
2. 给设计系统+先出故事板:没有设计系统就是千篇一律的AI默认风。设计系统是一个文件,定好颜色、字体、风格。他推荐
https://t.co/G9gKLtaWto 找参考。先出几张关键帧静图,改好风格再全量制作。
3. 让Claude开干,像导演一样给反馈。两个选择:
· HyperFrames:HeyGen团队的免费开源工具,Studio也免费,可拖动时间轴自己改。安装提示词:claude plugin
marketplace add heygen-com/hyperframes,再 claude plugin install hyperframes@hyperframes,然后做一条15秒动画开
场。
· 自建"小剪辑台":本地小应用,项目列表,时间轴上点一下打评论,"复制评论"按钮把所有评论合成一条提示词贴回给
Claude。他说用Opus 5.5最好。
· 如果你是Claude Team或Enterprise用戶,现在还有Claude Motion,在Claude里直接做同样的事。
````
