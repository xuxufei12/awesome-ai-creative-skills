## Prompt / 提示词

````text
提示词:
请帮我上网研究大家怎么用 Claude Opus 5.5 制作动画,整理成一套清楚的操作流程,再用这套流程亲手做一部「如何用 Opus
5.5 做动画」的教学动画。
第一阶段:资料收集
1. 搜寻范围:YouTube 教学影片(可读字幕或说明栏)、X/Twitter、Reddit(r/ClaudeAI 等)、个人部落格、Medium、GitHub
范例专案,以及 Anthropic 官方文件。
2. 关键字用中英文都搜,例如:「Claude Opus 5.5 animation」「Claude 做动画」「Claude Remotion」「Claude Manim」「Claude
SVG animation」「Claude HTML animation prompt」「Claude artifact animation」。
3. 以最近三月内的资料为主,至少参考 【10】 个以上不同来源。
4. 每个来源记下:作者、网址、用的工具或技术、他们的提示词写法、遇到的问题和解法。
第二阶段:整理分析
1. 先分类大家的做法。我不确定是用动画工具还是写程式码,请帮我厘清,可能包括:
程式码类:HTML/CSS/JS、SVG、Canvas、GSAP、Three.js、Remotion(React 影片)、Manim(Python 数学动画)、Motion
Canvas 等
工具搭配类:Claude 写脚本或分镜,再交给其他动画或影片工具
2. 比较各做法的难易度、适合对象、成品效果和优缺点,做成表格。
3. 归纳出一套「新手也能照做」的标准流程,例如:构想 → 写脚本/分镜 → 下提示词 → 生成程式码 → 预览修改 → 汇出
影片。每一步都附上实际可用的提示词范例。
4. 列出大神们共同提到的技巧,以及常见的错误。
````
