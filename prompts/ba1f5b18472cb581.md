## Prompt / 提示词

````text
操作系统环境：

- 选择一项：“Windows 11 风格桌面”或“macOS Sonoma 风格桌面”

- 如果未指定，则让模型选择最自然的操作系统界面

- 使用基于所选操作系统的真实界面元素

主题：

- 基于参考图像 A 的角色

- 使用半 3D 动漫风格渲染

- 清晰的阴影和立体的高光

- 以桌面吉祥物的形式与真实的操作系统界面互动

构图：

- 16:9 比例的逼真电脑桌面

- 包含逼真的应用程序窗口和图标

- 角色自然地位于这些界面元素上或周围

动作：

- 允许模型自由选择吉祥物般的行为，例如：

- 趴在窗口顶部边缘

- 坐在窗框上

- 触摸、查看或对图标做出反应

- 从文件夹或应用程序后面窥视

- 动作应感觉真实自然，略带趣味性

位置：

- 显示在真实的桌面上操作系统风格的桌面（Windows/macOS）

- 显示已识别的 UI 元素（例如，Chrome 窗口、文件夹图标、任务栏/Dock）

- 图标和窗口看起来逼真，但仅用作背景元素

风格：

- 半 3D 动画着色（柔和的卡通渲染风格）

- 使用清晰的阴影而非边缘光

- 干净的数字渲染，与真实的桌面 UI 自然融合

相机光照：

- 中性的正面或顶部光照，以创建清晰、方向性的阴影

- 柔和的环境光，以保持与桌面色彩的和谐

- 类似屏幕截图的正面拍摄角度

颜色：

- 桌面采用类似操作系统的冷色调

- 角色颜色精确地遵循参考图 A

- 强调阴影以增强 3D 立体感

文本：

- 除非必要，否则不添加文本

编辑说明：

- 使用参考图 A 以确保角色准确性

- 通过清晰的阴影平面强调 3D 立体感

- 确保角色显示在真实桌面 UI 元素之上

- 保持真实 UI 资源不变，仅用作背景元素背景信息

参考资料：

A：角色外观参考

其他：

- 高分辨率

- 逼真的操作系统用户界面渲染

- 清晰的合成和精确的图层分离

- 支持创意十足的吉祥物式动作
````
