# 一个 FPS 挫败瞬间 → 一期成片（一键到底）

> **目录约定（2026-10-13 起）**：`materials/` 和 `out/` 按风格分类、风格内从 00 编号，代码里的作品 ID（下文的 `<期>`）不变。下文 `<素材目录>` = `materials/<风格>/<编号-中文短题>/`，`<成片目录>` = `out/` 下同名目录。新一期开工时先建：`bash scripts/ep-dir.sh <期> materials --new <风格目录> <中文短题>`（自动取下一个编号，materials 和 out 一起建）；之后查路径用 `bash scripts/ep-dir.sh <期> materials` / `bash scripts/ep-dir.sh <期> out`。`npm run export -- <期>` 会自动把成片放进 `<成片目录>`。
> 本 skill 的风格目录是 `06-战术屏科普风`。

**用户调用这个 skill = 授权你从头做到交付**：成片 mp4、3:4 封面、发布文案、字幕稿，全部放进 `<成片目录>/`。中途**不问用户确认、不停在 Studio 等预览**，每做完一步用一句话同步进度；遇到要拿主意的地方按本文的默认值自己定，最后在交付报告里说明你替他定了什么。**不提交 git**，除非用户另外要求。

只有两种情况才停下来问：① 选题找不到任何一手资料、也没有可替换的相近角度；② 工具连续失败两次（渲染崩溃、生图接口报错）。其余一律自己解决。

样片：数据最好的是 ep25（躲进掩体还被打死，12 万播放）和 ep29（脚步听不出前后，8 万），选题和标题照它们的路子；代码**先照战术屏最近一期改**（目前是 `src/episodes/ep42-tap-fire/` 三个文件 + `tests/episodes/ep42-tap-fire.test.ts` + `audio/episodes/ep42-tap-fire.mjs`；文中举例的 ep35 也是同一套结构），不要从空白写。

动手前读：工程根目录 `CLAUDE.md`、`src/library/README.md`「战术屏科普风 tactical/」一节、本 skill 的五份 `references/`，**先读 `references/数据复盘.md`**：里面是抖音后台的真实数据，选题和标题怎么定都以它为准。所有 npm / npx / node 命令前先 `export NODE_OPTIONS=--max-old-space-size=4096`。

## 依赖（开源版说明）

除了下面两项，这个一锅出工作流的其他步骤（选题、timeline、画面、配乐卡点、字幕稿、导出、QA）都在仓库里：

- **封面**：作者用私人 Skill `ucloud-image-gen`（UCloud 上的 gpt-image 文生图）出 3:4 封面，文中的 `<ucloud-image-gen>` 指它的目录。换成任何文生图工具即可，Prompt 模板见 `references/封面与发布.md`；也可以直接 `npx remotion still` 渲一帧当封面。
- **标题**：备选标题的公式编号来自私人 Skill `dbs-xhs-title`，没有就让 Agent 按「≤ 20 字、留悬念不说答案」起。
- **配乐**：示例统一用音乐库的 we-never，这是作者已获授权的自用曲目，mp3 不随仓库分发。换成你自己有授权的曲子放进 `public/music/`，在 `audio/music.mjs` 的 `TRACKS` 登记，再用 `weilanx-creator-gilded-video/scripts/beats.py` 重测起音、小节长和重拍，改 `timeline.ts` 的网格，画面会跟着对齐。
- `scripts/stats.py` 读的是抖音创作者后台导出的「作品列表」xlsx，只在复盘数据时用。

## 0. 选题和期号

- **标题怎么写**：把玩家被冤枉的那一刻说出来，第二人称、痛点、问句，**≤ 12 个字**（长了标题卡会折行）。**答案不能是观众一眼猜得到的**：「跑着开枪为什么打不准」大家心里早有答案（跑着当然不准），开头跳出率是系列最高；「躲进掩体，为什么还被打死？」想不通，所以点进来。
- **用户给了选题**：直接用。如果题目是一个技巧（「急停」「点射」）或一个机制（「连跳」「帧数」），先把它翻成「冤」的说法当标题（「明明瞄准了头，子弹为什么飞了？」），技巧放到后半段；改写了什么在交付报告里说明。
- **用户没给**：先看 `materials/06-战术屏科普风/选题池.md` 的「待做」表按推荐顺序挑（做完把状态改成 ✅ 并填作品 ID）；池子用完再从 `references/选题与叙事.md` 的已做期数之外挑，按**冤 → 翻案 → 招**挑（2026-10-15 按后台数据定的，原因见 `references/数据复盘.md`）：① 冤：人人遇到过、会骂出声的瞬间，而且有人在背锅（自己菜、队友坑、系统黑、网络卡）；② 翻案：用一手资料 + 科学模型证明锅不在那儿，这是观众转发的动力（「你看，不是我菜」），分享率决定推荐量；③ 招：后半段给一个马上能用的技巧。纯机制、纯技巧的题分享率只有「冤」类的五分之一左右，不要单独当选题。排除对标账号做过的六个。
- **期号**：别的会话也在往 `src/episodes/` 里加期数，**写第一个文件之前**再 `ls src/episodes | tail -3` 一次，取最大号 + 1，作品 ID `epNN-英文短名`（下面记作 `<期>`）。撞号就顺延，不动别人的目录。
- **建素材 / 成片目录**：`bash scripts/ep-dir.sh <期> materials --new 06-战术屏科普风 <中文短题>`（中文短题 2～8 个字，如「残局手抖」，自动编号），之后 `<素材目录>` / `<成片目录>` 都用 `bash scripts/ep-dir.sh <期> materials|out` 查。

## 1. 查一手资料（不能跳过）

详见 `references/选题与叙事.md`。

- 只认原文：游戏官方博客 / 补丁说明、论文（PubMed `efetch` 拿摘要、OpenAlex 拿摘要、开放获取全文）、厂商研究页。读法：`mcp__web-reader__webReader`，或用 `python3 + urllib` 抓 HTML 去标签（被 403 时换 webReader）。搜索结果的摘要不算数。
- 要用的每个数字、每句原话写进 `timeline.ts` 常量，测试里断言；画面上用 `SourceCard` 标出处，示意图标「示意」。
- **只读到摘要、没读到正文**的细节（比如实验具体怎么操作），字幕里不要说得比摘要更具体；实在要用，在发布文案的内部核对清单里注明「据正文，未读到」。
- 可以自己算的数（概率、几何、比例）就自己算，测试里复算（ep31 的连跪概率、ep33 的 4/5、ep29 的 3a/v）。
- 一个选题至少要有 2 个独立来源，其中至少 1 个是同行评审或官方原文。

## 2. 锚词和七章分镜

结构公式见 `references/选题与叙事.md`，照着填：

- **锚词**：2～4 个字，一个词装下整期原理，结尾要能被重新定义（过去、对称、公平、坑队友、自动驾驶）。它在第 1 章结尾第一次出现（青色），第 48 小节砸出，情绪翻转句里再出现一次。
- **七章**：开场 / 机制 / 模型 / 实验或量化 / 反转或真相 / 怎么办 / 结尾，章节起点固定在第 0、9、16、24、32、40、48 小节。
- **开场 17 秒**：3D 射击场重演那一刻，三次重音（第 7、10、15 拍）给「失败 → 回放 / 结算 → 分屏 / 胜负条」三连；第 24 拍大字提问；第 28 拍一句话说一半，以「——」结尾。
- **开场常驻标题条**：第 0 帧起画面顶部挂 `HookBanner`（素材库 `stage.tsx`），文字是 timeline 里的 `HOOK_LINE`，一直挂到 `DARK_FROM` 随收暗退场。原因：观众平均只看 10–17 秒，多数人没等到 17.5 秒的标题卡就划走了，前 17 秒得一直告诉他「这期讲的就是你」。`HOOK_LINE` 是标题的第二人称加长版，可以比标题多几个字（≤ 20 字），把被冤枉的感觉说足，问题部分用 `〖〗` 标红：「你明明躲进了掩体，〖为什么还被打死〗？」。第 24 拍的大字提问不要和它重复，换个角度问。
- **怎么办（招）**：四张方法卡（`StepGrid`），每张 ≤ 8 个字；能从出处推出来的方法优先，纯建议也行，但要在发布文案的核对清单里写明「建议」。技巧是「招」，结尾暖色射击场里用它赢一次，让观众看到用了之后的样子。
- **情绪翻转**：替观众卸包袱（「你不是 X，你只是 Y」），把翻案的结论说成一句能转发的话；评论区问题人人都有答案。

## 3. 写 timeline.ts（全片唯一时间表）

照最近一期的 `timeline.ts` 改：网格、`HIT` / `HIT2` / `DARK_FROM*`、`CUES`、`HALF_BEATS`、`CHAPTERS`、`SHOTS`、事实常量、`SFX`，再加一个 `HOOK_LINE`（开场常驻标题条的文字）。硬规则：

- `CUES` 每句挂在拍点上，`null` 行同一行写 `// 说明`（字幕稿脚本会读）。只有 `HALF_BEATS` 里的两句能以「——」结尾。
- `SHOTS` 首尾相接，最后一个是 `ask: [fb(59), DURATION]`；每个章节起点都是某个镜头的起点。
- **画面里每个元素的出场帧必须落在它所在镜头的时间范围内**（ep35 踩过：因果链后两个节点在镜头切走后才点亮，从头到尾没露面）。写完对一遍 `ats` / `lit` / `turnAt` 和镜头起止。
- **timeline.ts 不能 import 别的 .ts / .tsx**（`qa.mjs` 和 `subtitle-doc.mjs` 用 Node 直接加载它，只能剥掉本文件的类型）；需要素材库里的纯函数就在 timeline 里自己写一份。
- 卡点和音效音量表见 `references/卡点与音效.md`。开场第 0 拍附近配乐自己有一下重音，**第一声枪别放在第 0～1 拍**，会被盖住。

## 7. 自动自查（自己修，最多三轮）

```sh
node .claude/skills/weilanx-creator-fps-video/scripts/qa.mjs <期>
```

它会给每个镜头切走前一帧（这时该出现的东西都已经出来了）、两个爆点的 −16 / −3 / +2 帧拼成网格，测整片响度，列出被配乐盖住的冲击类音效。产物在 `/tmp/<期>/qa/`，用 Read 逐张看 `sheet-*.jpg` 和 `hits.jpg`，按 `references/画面与镜头.md` 末尾的清单查：

- 开场四个镜头（hook / shot / replay / split）的切走前一帧都要看得到顶部标题条，而且没挡住人靶、准星和关键图形（要被看见的东西放在 y > 220）；question 镜头那帧已经收暗，标题条跟着退场
- 文字重叠、出画、折行（标题卡、方法卡、标签）；元素压到字幕区（y > 860）
- 该出现的东西没出现、示意图空间关系不对、人靶被遮挡、准星没跟着目标
- 爆点：−16 已开始收暗、−3 静止、+2 标题或锚词已经亮起来
- `report.md`：整片约 −15.5 LUFS、真峰值 ≤ −1.0 dBFS；偏弱音效加音量或挪开

修完只重渲改过的镜头：`qa.mjs <期> --frames-only=镜头A,镜头B`；改了音量再跑 `--audio`。三轮后还有小瑕疵，记进交付报告，不要无限打磨。
