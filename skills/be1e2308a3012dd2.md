# video-explainer

Code-animated explainer shorts (the kp series) with no AI footage - Claude writes an HTML canvas animation, Chrome renders it frame by frame at 60 fps, with an edge-tts voice-over and subtitles that highlight keywords in yellow, vertical 1080×1920. Text, numbers, curves and formulas are 100 % accurate and crisp. Good for mental models (compound interest, marginal thinking, probability, sunk cost…), maths / personal-finance / science principles and data comparisons. Flow - pick the topic + verify the numbers → about 9 lines of copy → write the animation HTML → self-check keyframe stills → full render → QC → cover + Douyin / Xiaohongshu post. Sample episode kp01 compound interest. Triggers - explainer animation, code animation, explain a principle clearly, curve animation, data animation, knowledge video, like the compound-interest one, next explainer episode, kp01, /video-explainer. Q&A thinking stories with Shuai & Mei use video-talk, not this.

# Code-animated explainers (kp series)

All commands run from the repo root.
Sample: `scripts/kp01.json` + `tools/code_anim/kp01_compound.html` → `works/kp01_compound-interest/`
Full reproduction steps: `works/kp01_compound-interest/REPRODUCE.md`

## Why code instead of AI video

AI video models can't write legible text or draw accurate curves and data. In a code animation every frame is computed: numbers really count up (1.01^d calculated day by day), curves follow the formula, type is crisp, it costs nothing and doesn't heat the machine (CPU screenshots only).

## House rules

1. Show the user a few keyframe stills (`--stills`) to agree the style before rendering the full video
2. Each episode explains exactly 1 concept, 40–60 s, about 9 narration lines
3. Every number must be computed in Python before it goes into the copy (e.g. 1.01^365 = 37.78, 0.99^365 = 0.0255, ratio 1481)
4. Delivery: `works/kpNN_<name>/` contains `kpNN.mp4`, `kpNN_cover.jpg`, `kpNN_post.txt` (one version each for Douyin and Xiaohongshu); add the episode to the works list in `README.md`
5. Report the actual time taken

## Step 1: copy `scripts/kpNN.json`

Copy `scripts/kp01.json` and change `name` (sets the works folder name), `html` and `lines`:
- `tts`: what the voice reads. **Write numbers the way they should be spoken** ("one point zero one to the power of three hundred sixty-five") and avoid words the voice mispronounces (for Chinese voices: write numbers in characters and avoid polyphonic characters)
- `sub`: on-screen subtitle with digits; text inside `[...]` is highlighted in yellow (e.g. `"[1%] better every day"`); `\n` breaks the line; keep lines short (about 30 Latin characters, or about 16 characters for Chinese)
- `rate`: per-line speaking rate — slow down emotional lines (`-8%`), speed up the climax (`+5%`)
- Structure: hook question (0–6 s) → reveal the number → counter-intuitive point ("But here's the strange part…") → climax visual → one-sentence definition ("This is compound thinking") → question for the comments
- Narration voice: `en-US-AndrewNeural` (set `voice` in the JSON; any edge-tts voice works)

## Step 2: animation `tools/code_anim/kpNN_<english-name>.html`

Copy `kp01_compound.html`, keep the shared parts (easing functions, `text` / `row` / `pop` / `scaled`, background particles, `header`, `subtitle`, `layer`, `icon`) and rewrite only the scene functions. Conventions:
- The page must define `window.ready` (waits for fonts) and `window.draw(t)` (depends only on t, fully deterministic)
- The placeholders `/*__TL__*/[]` (timeline), `/*__D__*/40` (total duration) and `__FONT__` (bold font) are injected by `render.py`
- Write all scene timing in terms of `S(i)` / `E(i)` (start / end second of narration line i), so the animation re-aligns to the voice-over automatically when the copy changes
- `layer(t, a, b, fn)` handles cross-fades between scenes
- Font: `tools/fonts/Inter-Bold.ttf` by default (Latin only). For Chinese on-screen text, set `STUDIO_FONT=/path/to/a/CJK-font.otf`

Safe area (1080×1920): title y < 380; main content y 450–1400; subtitles y 1560–1720; **the bottom 200 px and right 120 px are covered by the Douyin UI buttons — keep content out of them**.

Palette: dark navy gradient background `#0a0f27 → #1c2152`, gold `#ffc93c` for growth and emphasis, blue `#6f8dff` for the comparison group, red `#ff6b6b` for warnings.

## Step 3: self-check stills → full render

```bash
python3 tools/code_anim/render.py scripts/kpNN.json --stills 0,5,12,20,30,40   # about 20 seconds
caffeinate -i python3 tools/code_anim/render.py scripts/kpNN.json             # a ~46 s video takes about 7 minutes
```
Use the system `python3` (with playwright installed, driving the local Google Chrome); edge-tts is picked up from PATH or `.venv/bin/edge-tts` (render.py handles this). Voice clips are cached, so changing only the animation doesn't re-synthesise the voice.

Look at every still: text overflowing or overlapping, wrong numbers, and **the first frame must not be empty** (Douyin and chat apps use frame 1 as the preview).

## Step 4: QC + cover

```bash
ffprobe -v error -show_entries stream=width,height,r_frame_rate,nb_frames:format=duration -of compact works/<dir>/kpNN.mp4
ffmpeg -nostats -i works/<dir>/kpNN.mp4 -af ebur128=framelog=quiet -f null - 2>&1 | grep "I:"   # about -16 LUFS
ffmpeg -v error -y -ss <most striking second> -i works/<dir>/kpNN.mp4 -frames:v 1 -q:v 2 works/<dir>/kpNN_cover.jpg
```
(`check_video.py` belongs to the older pipeline and needs a spec — not used here.)

## Step 5: post copy (one for Douyin, one for Xiaohongshu)

- **Douyin**: short title with a number + contrast ("1 % better every day: 1481× apart after a year"); 3–4 lines of description ending with an engagement question; 5 hashtags; pick light instrumental music from the library, volume 15–20
- **Xiaohongshu**: shorter title, may include 1 emoji; body in first person, in short paragraphs with emoji sub-headings, giving a "save-worthy takeaway"; 8–10 hashtags; big text on the cover
- On both platforms **tick the AI label**: the voice-over is AI-synthesised (Douyin: "Content is AI-generated"; Xiaohongshu: "Note contains AI-synthesised content")
- No superlatives ("best", "number one", "absolutely", "must-watch") and no engagement bait ("like and follow")

## Pitfalls

| Problem | Cause | Fix |
|---|---|---|
| Emoji render as blanks | Headless Chrome screenshots don't draw colour emoji | Draw icons in code with `icon()` (book, coin, heart); draw arrows with lines |
| Frame 1 shows only a semi-transparent card | The opening has a pop-in animation | Set the start time of first-screen elements to -1 so frame 1 is complete |
| Exponents aren't superscript | `row()` aligns to the baseline by default | The 4th argument of `row` is a y offset; pass -20 for superscripts |
| A label covers the end of a curve | The end point is in the top-right corner | Offset the label down and to the left |
| The voice reads numbers wrongly | TTS is unreliable with bare digits | Spell numbers out in the `tts` field |
| 30 fps isn't smooth enough | — | Render 60 fps frame by frame directly; no interpolation |
