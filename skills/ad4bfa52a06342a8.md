# 风格化着色节点组使用指南 (Stylized Shading Node Groups)

本技能教你正确使用 **blender_Stylized-Shading-Tools** 插件（"风格化着色工具"，作者 路人甲）提供的 NPR 材质节点组。插件通常通过 Blender MCP 的 `execute_blender_code` 由 AI 驱动，本文所有代码示例都基于 `bpy`。

## 1. 资源与安装前提

- 插件目录：`E:\rj\blender\plugin\addons\blender_Stylized-Shading-Tools`
- 材质节点组源文件：`shader file/my shader.blend`
- 节点修复模板源文件：`fix_node/fix_node.blend`
- 要求：Blender 3.4+，插件已启用（侧边栏 N → "风格化材质"标签页）
- ⚠️ 参数名以本文为准（已按 Blender 5.1 实测 schema 校正）：散装 `Z轴变化` 的输入是 `Z轴最小范围`/`Z轴最大范围`（不是 From Min/Max）；光源拓展组 `Color` 默认是灰色 (0.5~0.8) 而非极黑。

## 2. 节点组清单

| 类别 | 节点组 | 说明 |
|---|---|---|
| 全能 | `多功能风格化shader` | 283 节点一站式材质，含下面全部效果，参数按面板分组 |
| 散装 | `主节点` | 核心二分光照（亮部/暗部），是散装管线的第一级 |
| 散装 | `轮廓光` | 边缘光（Facing/Fresnel） |
| 散装 | `高光` | 卡通高光（Specular BSDF + 遮罩） |
| 散装 | `反射` | Voronoi 反射图案（单色/多色） |
| 散装 | `脏迹` | 双噪声脏迹（fBM/Multifractal） |
| 散装 | `AO` | 环境光遮蔽暗角 |
| 散装 | `Z轴变化` | 相机深度渐变染色 |
| 渐变 | `渐变` | 控制器空物体驱动的色彩渐变 |
| 光源拓展 | `原理化拓展光源` / `金属拓展光源` / `光泽拓展光源` / `漫射拓展光源` | 基于灯光组(Lightgroup)的 NPR 分层光照（Shift+A → 风格化节点 → 光源拓展BSDF） |
| 辅助 | `纹理坐标` / `混合颜色` / `映射范围` / `Z深度钳制` | 小工具组件 |
| 修复 | `Surface Curvature` / `Curvature` / `Cavity` / `Co-Planar Edge Detection` / `Shading Models` / `Kuwahara`(+Least/Quadrant) | 节点修复工具模板，也可直接用作 NPR 功能组 |

## 3. 添加节点组（AI 必须知道的操作）

```python
# 方式A：一键添加任意节点组
# 在节点编辑器环境 = 加到光标处；在物体模式 = 给所有选中网格加材质并连到输出
bpy.ops.node.style_add_custom_group(group_name="多功能风格化shader")
bpy.ops.node.style_add_custom_group(group_name="原理化拓展光源")   # 光源拓展BSDF 同此操作符

# 方式B：一键添加全部散装组（7 个组横向排开，间距300）
bpy.ops.node.add_bulk_groups()
# ⚠️ 注意：bulk 模式只自动连接 主节点→材质输出！其余 6 组需要手动串联（见 §4）

# 方式C：一键色彩渐变（自动创建球体控制器空物体 "{物体名}_控制器"）
bpy.ops.node.add_gradient_group()
```

Shift+A → 风格化节点 菜单结构（节点编辑器里）：
```
风格化节点
├── 多功能风格化shader
├── 基础风格化节点组（原"风格化节点组1"）：主节点/轮廓光/高光/反射/脏迹/AO/Z轴变化
├── 辅助节点组（原"风格化节点组2"）：渐变/纹理坐标/混合颜色/映射范围/Z深度钳制/物体随机化
├── 光源拓展BSDF：原理化拓展光源/金属拓展光源/光泽拓展光源/漫射拓展光源
└── 体积特效：体积雾/体积光（光柱）
```

> ⚠️ 创意纹理（排线纹理/网点纹理/整体HSL/对比度）**已从菜单移除**，作为 skill 创意内容保留：仍可通过 `bpy.ops.node.style_add_custom_group(group_name="排线纹理")` 等直接调用（程序化按需构建）；「物体随机化」已并入上方「辅助节点组」菜单。

**重要行为**：插件每次添加都会从 .blend **强制重载模板**（旧的同名组会被改名 `_old` 备份）。所以直接修改组实例的输入默认值即可，不用担心污染模板。

**散装组串联（bulk 后 AI 必做的一步）**——推荐管线：

```
主节点.Result → 轮廓光.Color → 高光.Color → 反射.Color → 脏迹.Color → AO.Color → Z轴变化.Color → 材质输出.Surface
```

## 4. 参数设置代码模式

所有效果组都是 "Color 进 → Result 出" 的串联单元。取到组实例节点后按名字设置：

```python
import bpy
mat = bpy.context.active_object.active_material
node = next(n for n in mat.node_tree.nodes if n.type == 'GROUP' and n.node_tree.name.startswith('主节点'))

node.inputs['亮部范围'].default_value = 0.55          # 浮点
node.inputs['过渡方式'].default_value = 'Smoother Step'  # 菜单端口用字符串
node.inputs['基础色'].default_value = (0.9, 0.2, 0.2, 1.0)  # 颜色是 RGBA 四元组
node.inputs['Normal'].default_value = (0.0, 0.0, 1.0) # 向量
```

**AI 调参首选接口（推荐替代裸 bpy 代码）**：

```python
# 原位改参（不重新添加节点组）：JSON 格式 {组基础名: {参数: 值}}
# 菜单参数用字符串，颜色用 RGBA 列表，找不到的组/参数会被忽略并报告
bpy.ops.node.edit_group_params(params_json='{"主节点": {"亮部范围": 0.75, "过渡方式": "Stepped Linear"}, "高光": {"高光开关": 1.0}}')

# 查询当前材质结构（调参前必做）：导出所有组实例的模板名/基础名/当前参数/连线状态
bpy.ops.node.query_material()   # 结果写入 bpy.app.tempdir/material_query_dump.txt 并打印
```

若需查看某节点组的完整参数 schema（名称/类型/默认/范围），用：
`bpy.ops.node.query_group_params()`（在节点编辑器选中组，或选中带材质的物体）。

## 5. 菜单选项速查

- 过渡/映射方式：`Linear` / `Stepped Linear` / `Smooth Step` / `Smoother Step`
- 混合模式（Blending Mode）：`Mix, Darken, Multiply, Color Burn, Lighten, Screen, Color Dodge, Add, Overlay, Soft Light, Linear Light, Difference, Exclusion, Subtract, Divide, Hue, Saturation, Color, Value`
- 轮廓光计算：`Facing` / `Fresnel`
- 反射模式：`单色` / `多色`
- 噪声类型：`fBM` / `Multifractal`
- AO 染色：`自身颜色` / `染色`
- 光源拓展颜色空间：`HSV` / `HSL`
- 纹理坐标：`Generated, Normal, UV, Object, Camera, Window, Reflection`

### 6.8 多功能风格化shader（全能，参数分组）
面板顺序：光照 → 颜色 → 亮部染色 → 暗部染色 → 高光 → 轮廓光 → 反射 → 脏迹 → AO → Z轴变化。

- **光照**：`亮部范围` 0.5、`暗部范围` 0.45、`线性/阶梯` 0、`阶梯步数` 30（默认）、`Roughness` 0、`Normal`
- **颜色**：`基础色` (0,0,0)、`颜色模式:混合/正片叠底` 0
- **亮部/暗部染色**：各含 颜色/强度/色相/饱和度/明度（见 6.1）
- **高光**：`高光开关` **0（默认关）**、`高光范围` 0、`软硬钳制:小值/大值` 0/0、`染色模式:混合/滤色` 0、`高光染色` (0,0,0)、`高光位置`
- **轮廓光**：`轮廓光开关` 0、`模式:统一/亮部暗部拆分` 0、`模式:菲涅耳/层权重` 0、`强度` 0.8、`统一轮廓光范围` 1、`统一轮廓光颜色` 红、`亮部/暗部轮廓光范围` 0/1、`亮部/暗部轮廓光颜色`
- **反射**：`反射强度` 0.5、`反射范围` 0、`多色/单色` 0、`随机多色进入节点内部修改`、`单色颜色` (0.323,0.034,0.499)
- **脏迹**：`脏迹深浅[0=无脏迹]` 0.5、`纹理映射:物体/摄像机` 0、`Location/Rotation/Scale`、`脏迹色` (0.2,0.2,0.2)
- **AO**：`AO开关` **0（默认关）**、`自身颜色/染色` 0、`AO染色色` (0.8,0.8,0.8)、`范围` 0、`Hue/Saturation/明度` 0/0/0、`Distance` 0
- **Z轴变化**：`Z轴变化开关` 0、`Z轴范围模式:线性/更平滑` 0、`From Min/Max` 0.3/1.0、`自身颜色/染色` 0、`Hue/Saturation/明度` 0.5/1/1、`影响系数` 1、`颜色模式:混合/正片叠底` 0、`Z轴颜色` (0.5,0.5,0.5)

> ⚠️ 全能组默认开关与散装组不同：全能 高光关/AO关/Z轴关；散装 高光关/AO关。改参前先用 `query_material` 看实际状态。

### 6.9 渐变（控制器驱动）
一键添加后会自动创建球体控制器空物体 `{物体名}_控制器`（父级为物体）并赋给组内 Texture Coordinate.002 的 Object。移动/旋转控制器 = 移动/旋转渐变方向。
- `基础色` (0.5,0.5,0.5)、`Menu`(坐标来源) 空物体坐标、`渐变强度` 1、`渐变色` (1,0,0.084)、`反转方向` 0、`Location/Rotation/缩放`、渐变类型 Linear、`Texture Coordinate` Object、`Map Range` Stepped Linear、`阶梯步数` 4、`Blending Mode` Multiply、反转菜单 不反转
- 并入式连接：原材质 Surface 结果 → 组输入，组输出 → 材质输出（即渐变叠加在原材质上）

### 6.11 光源拓展BSDF 系列（Shift+A → 风格化节点 → 光源拓展BSDF）
**原理**：组内用**双份 BSDF**（都绑定 `Lightgroup ID`），`Shader to RGB` 提取"被该灯光组照亮的颜色"；蓝通道经 `Map Range`（可阶梯化）重映射得到亮度系数；颜色再经 `HSV`/`HSL` 处理，最后按 `Blending Mode`（默认 Add）叠到输入的 `Color` 上。适合做"某盏灯只影响指定材质/指定区域"的 NPR 分层光照。

| `Menu` | HSV | 菜单 | 灯光颜色处理空间：`HSV` / `HSL` |  |
| `Map Range` | Smoother Step | 菜单 | 亮度系数重映射曲线（Linear/Stepped Linear/Smooth Step/Smoother Step） |  |
| `Steps` | 4 | — | 阶梯模式色带级数 |  |

| `Color` | 灰 (0.5~0.8) | 颜色 | 基础色（漫射/光泽默认 0.8 灰，原理化 0.5 灰，金属 0.617 棕；串联时被上一组 Result 覆盖） |  |

## 7. 风格配方库（apply_style_preset 一键套用，共 9 个）

通过 `bpy.ops.node.apply_style_preset(preset='配方key')` 一键添加+串联+设参。所有配方基于散装组（或光源拓展组），可在 Blender 面板"风格化材质 → 风格配方"下拉选择。

> 配方按**节点组组合**命名（避免材质形容词），每个配方 = 一种不同的组合结构；具体材质观感在套用后通过 `edit_group_params` 调色/调参实现。

| 配方key | 名称 | 使用组 | 组合结构 |
|---|---|---|---|
| `tone_base` | 二分基础 | 主节点 | 仅二分光照（所有组合的地基） |
| `tone_rim` | 二分轮廓 | 主节点+轮廓光 | 二分 + 边缘描边（Facing 深色轮廓） |
| `tone_spec` | 二分高光 | 主节点+高光 | 二分 + 高光点 |
| `tone_detail` | 二分质感 | 主节点+脏迹+AO | 二分 + 表面做旧/纹理细节 |
| `tone_depth` | 二分景深 | 主节点+Z轴变化 | 二分 + 相机深度渐变染色 |
| `tone_gloss` | 二分光泽 | 主节点+高光+反射 | 二分 + 锐利高光 + 反射图案 |
| `tone_rim_spec` | 二分轮廓高光 | 主节点+轮廓光+高光 | 二分 + 菲涅耳亮边 + 点状高光 |
| `tone_full` | 二分全效 | 主节点+轮廓光+高光+脏迹+AO | 全部散装组串联（二分+边缘+高光+做旧） |
| `light_layering` | 灯光分层 | 主节点+漫射拓展光源+光泽拓展光源 | NPR 分层光照（需灯光组） |

**推荐起始参数**：

| 组合 | 配方 |
|---|---|
| 二分基础 | 主节点：`过渡方式=Smoother Step`、亮部≈0.5、暗部≈0.45、阶梯步数 2~4 |
| 二分轮廓 | 主节点 + 亮部暖色/暗部冷色染色 + 轮廓光(面朝向 Facing, 深色, 宽度 0.1~0.3) |
| 二分高光 | 主节点 + 高光(小, 钳制 0.2~0.8) + Kuwahara(Size 0.3~0.5) |
| 二分质感 | 主节点(亮部范围=1, 暗部范围=0) + 脏迹(fBM, Scale 5, 强度 0.9, Multiply) + AO(Distance 0.3, 范围 0.8) |
| 二分景深 | 主节点 + Z轴变化(Z轴最小范围 0.3→Z轴最大范围 1, 蓝灰染色) |

**灯光组分层配方用法（light_layering）**：
1. 场景 → View Layer Properties → Light Groups → 新建 `KeyLight`（=ID 0）和 `FillLight`（=ID 1）
2. 给主光 `light.data.lightgroup_id = 0`，补光 `= 1`
3. 套用 `light_layering`：漫射拓展光源(主光暖色) + 光泽拓展光源(补光冷色) 叠加到主节点结果上
4. 调 `Lightgroup ID` 可换组；`灯光亮度系数` 输出可接别的组做 Factor

## 8. 常见陷阱

1. **散装组默认值 ≠ 全能组**：开关默认值不同（散装 高光关/AO关；全能 高光关/AO关/Z轴关）。改参前先 `query_material` 确认实际状态。
2. **bulk 后必须串联**：只有 主节点 接到输出，其余组是"孤立"的，不串联就没有效果。
3. **颜色默认值是 RGBA 四元组**，赋值漏第 4 个通道会报错；`edit_group_params` 用 JSON 数组 `[r,g,b,a]`。
4. **菜单端口用字符串赋值**（`'Smoother Step'` 而非数字）。
5. **修复工具**：遇到名称含 `Surface Curvature / Shading Models / Kuwahara / Cavity / Co-Planar Edge Detection / Curvature / Shader Info` 的损坏节点组，用 `bpy.ops.node.fix_selected_nodes()` 或 `bpy.ops.node.fix_all_nodes()`。
6. **渐变控制器**：重复添加会删除旧的 `{物体名}_控制器` 并重建；控制器在物体模式下选中并移动即可调整渐变。
7. **光源拓展组依赖灯光组**：Blender 5.x 在 View Layer Properties → Light Groups 建组，`light.data.lightgroup_id` 分配；`Lightgroup ID` 默认 0 响应 0 号组，-1 响应所有。
8. **Z轴变化参数名**：散装版是 `Z轴最小范围`/`Z轴最大范围`；全能版才是 `From Min`/`From Max`。用错名字会被 `edit_group_params` 静默忽略（报告"未找到"）。
9. **edit_group_params 是原位改参**：只改已存在组实例的参数，不会添加新组；套新配方用 `apply_style_preset`。
10. **反射范围上限**：`反射` 节点的 `反射范围` ≥2 时整个模型会被纯反射色覆盖（Voronoi 图案过密）。**不要超过 1.2，推荐 0.7**；`反射强度` 控制可见度、`反射范围` 控制图案密度，两者分开调。

## 9. 扩展模块（可选，本插件作者另提供了 style_presets.py）

若插件目录中存在 `style_presets.py`（本技能配套扩展，v2：13 配方 + 调参/查询接口），额外提供：

# 第二部分：效果实现映射 —— 把 Stylized Asset Suite 的参数逻辑翻译成"本插件节点组"

> 目标：**用户用自然语言描述想要的风格/效果 → AI 理解需求 → 用本插件的节点组（主节点/轮廓光/高光/反射/脏迹/AO/Z轴变化/渐变/光源拓展BSDF 等）实现**。
> 依据：另一套 NPR 插件 **Stylized Asset Suite**（shaderaddon，crzyzha）的材质参数语义（完整参考见本技能目录 `sas_reference.md`）。
> 它没有直接搬进本插件，而是把它的**参数处理逻辑**映射到本插件已有的节点组上；映射不了的列为 ⚠️（见 §M3），需要新增节点组或外部手段。

## M5. 对话工作流（AI 推荐执行顺序）

1. **听懂需求** → 按 §M1 归类，必要时追问 1 个关键问题（如"要写实还是卡通？""描边粗还是细？"）
2. **选组** → 查 §M2/M4 确定本插件组组合（含创意模块组）
3. **搭组** → `apply_style_preset` 套最接近配方，或 `add_bulk_groups` + 手动串联（见 §4），创意组用 `style_add_custom_group`
4. **自省** → `query_material` 看当前参数（必做）
5. **调参** → `edit_group_params` 按 §M4 决策表微调
6. **验证** → 渲染截图对比，迭代 2~4 步
7. **无现成方案** → 如实告知 + 替代方案 + **发散思维设计新节点组**（按 §P4 构建模式，用户同意后实现）

## P4. 发散思维构建模式（AI 遇到新需求时怎么"造"）

用户要求的效果如果插件与创意模块都没有现成组，按此模式**新建节点组**（而不是拒绝）：

1. **设计**：想清楚效果拆成哪些标准节点（纹理/映射/混合/BSDF），参数都做成组输入
2. **构建**：仿照 `creative_effects.py` 的 `_new_group/_inp/_n/_link` 模式，用 `execute_blender_code` 建组，并把组名加进 `creative_effects.CREATIVE_GROUPS` + `_BUILDERS`（或提示用户把它写进插件）
3. **接线**：`material_functions.ensure_node_group_loaded` 已对创意组走程序化构建分支，新组名加入清单即可被 `style_add_custom_group` 识别
4. **验证**：建猴头测试 + 渲染对比 + `edit_group_params` 调参
5. **沉淀**：把新组写进本技能（参数表 + 用法），方便下次直接调用

## 10. 作者补充

所有矢量和浮点数的相关输入接口，都可以混合进一个噪波纹理作为对参数的一个扰乱效果，简单使用参考之一：噪波纹理连接浮点运算的乘法节点，这一个节点能控制噪波纹理影响强度，再连接一个浮点运算乘法节点，这一个效果是将噪波纹理与浮点值相乘产生效果

> 本技能目录 `sas_reference.md` 保留为"参数逻辑参考手册"（SAS 各效果的输入默认值/内部结构），供 §M2 映射与 P4 发散设计时查证语义；它不是本插件的使用指南。

> 本技能目录 `material_pipeline.md` 为**材质管线与灯光响应补充文档**（作者补充，务必先读）：补充「主节点 ↔ 光源拓展BSDF」的核心分工（主节点对灯光反应做二分/平滑与亮暗染色；光源拓展组对 Lightgroup ID 反应做多光源染色）、推荐串联管线，以及 EEVEE 实机踩坑修复（渐变控制器关联/双 Background+Is Camera Ray 世界环境/漫射组压暗问题等）。制作或还原材质时，先按该文档的分工定位选择节点组，再按本指南调参。
