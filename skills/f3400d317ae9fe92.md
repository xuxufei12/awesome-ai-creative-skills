# video-lineart

Blender line-art animation (white lines on black, minimal 3D sets, slow camera moves, small white subtitles, calm narration, in the style of plotome) - Claude writes a Blender Python script that builds the set and animates the figures and cameras, EEVEE + Freestyle render it frame by frame, with an edge-tts voice-over, ASS subtitles and ambient sound, vertical 1080×1920 at 30 fps. Good for quiet, emotional little stories that make a point (sunk cost, opportunity cost, financial freedom…) or explanations that benefit from 3D space. First sample is kp02 sunk cost (a cinema). Triggers - line-art animation, Blender, black-and-white line animation, like plotome, minimal 3D animation, /video-lineart.

# Blender line-art animation

All commands run from the repo root.
Sample: `scripts/kp02.json` + `tools/blender_line/kp02_scene.py` + `tools/blender_line/make.py`
Blender: 5.x on PATH (install with `brew install --cask blender`). Measured limits are in `docs/capability-map.md`.

## Steps

1. **Copy** `scripts/kpNN.json`: copy kp02. Each line has `tts` (spell numbers out as they should be spoken), `sub` (subtitle), `rate` (slow storytelling down overall, -5 % to -15 %) and `shot` (which camera the line belongs to). Set `gap` to 0.6 s so the narration can breathe; `title` is the small title at the top.
2. **Scene** `tools/blender_line/kpNN_scene.py`: copy kp02_scene.py. Keep the basics (materials, `box/cyl/sph/torus/plane/text/empty/camera/look/key/vis`, the Freestyle setup, the `person()` figure and `pose_person`) and rewrite the set building and `animate(f)`.
   - Time all animation in narration time `S(i)` / `E(i)` (seconds); one camera per shot, switched by timeline markers named after `shot`
   - Every object is black emission (only the white lines show); light sources such as a screen or light through a door use `emission_mat`
   - Large planes use a subdivided grid; hide objects that aren't on screen with `vis(o, False, f)`
   - Layout: keep y < 300 at the top for the small title, subtitles at y ≈ 1590, the subject in the middle
   - Font: `tools/fonts/Inter-Bold.ttf` by default; set `STUDIO_FONT` to a CJK font for Chinese 3D text or subtitles
3. **Self-check stills** (frame number = seconds × 30):
   ```bash
   python3 tools/blender_line/make.py scripts/kpNN.json --stills 50,200,340,480,690
   ```
   Stills land in `assets/kpNN/stills/`. Check each one: is the figure in frame or hidden behind something like a seat back, do lines from behind show through, do the lines interfere with the subtitles?
4. **Preview**: `caffeinate -i python3 tools/blender_line/make.py scripts/kpNN.json --preview 10` (about 2 minutes) → send to the user for approval
5. **Full video**: `caffeinate -i python3 tools/blender_line/make.py scripts/kpNN.json` (≈ 50 s of video takes about 9 minutes) → written to `works/<name>/kpNN.mp4`
6. Cover, post copy (Douyin + Xiaohongshu) and README update, same as `video-explainer`

## Room for improvement

The figures are simple (puppet-like); walking is mechanical; currently there is only projector hum — no music or sound effects (footsteps, doors). For a more polished piece, synthesise effects with `anoisesrc` / `sine`, or source them from a CC0 library.
