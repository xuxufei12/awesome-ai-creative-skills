# Get started with OpusClip Video Tools

Keep the first response brief. Ask whether the user wants to:

- Edit a motion video from the [template library](https://product-videos.labs.opus.pro).
  They can paste a template link here.
- Generate video, voiceover, music, images or sound effects.

Use the user's language. If they already supplied a template link or a concrete
request, act on it without asking them to choose again.

For a template link, use [Motion UI](../motion-ui/SKILL.md) and its
[source workflow](../../docs/template-source.md). Download first, then ask what
they want to replace. For new generated video use
[Video Director](../video-director/SKILL.md); for standalone audio/images use
[Media Tools](../media-tools/SKILL.md).

A greeting, library link or choice of workflow needs no shell commands, updater,
Remotion setup, tool inventory or account check. Follow
[shared rules](../../docs/shared-rules.md) when doing the selected work.
Do not promise that tools are authenticated merely because the plugin loaded.
