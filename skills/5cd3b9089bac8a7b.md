# video-talk

The "Top Thinking" series - two fixed characters, Shuai (wise in a sleepy, unassuming way; tells the story and lands the point) and Mei (impatient, asks the questions), talk in Q&A form and use one original little story to explain one mental model in under a minute (compound interest, inversion, iteration, playing to your strengths, differentiated competition, sunk cost…). Vertical 3D cartoon, two voices, subtitles coloured by speaker, generated locally at zero cost. Flow - write the copy document for the user to review → user approves → preview of the first 3 shots → user approves → full episode → QC → post copy. Triggers - Top Thinking, Shuai and Mei, thinking story, explain a mental model, next thinking episode, Q&A philosophy, /video-talk.

# Top Thinking · Shuai & Mei (Q&A, under a minute)

All commands run from the repo root. `python` below means a Python 3.11+ environment with numpy / opencv / pillow (e.g. a conda env).
Character card: `characters/xiaoshuai-xiaomei.md` (looks, personalities, voices, prompt lock blocks). Episode 1 sample: `scripts/zy01.json`.

## House rules (always follow)

1. **There must be an idea and a document, approved by the user, before generating**: first write `works/zyNN_top-thinking_<model>/PLAN.md` (copy + shot list + compliance) and send it to the user for review
2. **Each episode is under a minute** and covers exactly 1 mental model; about 120–170 Chinese characters of dialogue (roughly 130–180 English words)
3. **The leads are always Shuai and Mei**: Shuai = sleepy-eyed and unassuming but wise (squinting eyes, green cardigan, thermos cup); Mei = impatient questioner (ponytail, glasses, denim jacket, orange backpack)
4. **Preview the first 3 shots first**, and do the rest only after the user approves; report the actual time taken on delivery

## Step 1: copy (in the plan document)

Structure (borrowed from the classic Q&A-plus-one-theme format of animated "little monk" philosophy shorts — structure only; no monks and none of that IP):
| Section | Who | Time |
|---|---|---|
| Hook: one concrete worry | Mei | 0–5 s |
| A question back, or "There was once a guy in the village…" | Shuai | 5–10 s |
| An original little story, 2–3 beats, cutting to story visuals | Shuai narrates | 10–35 s |
| Mei follows up or has her "aha"; Shuai names it ("This is called XX thinking") + one memorable line | both | 35–50 s |
| Playful ending + question for the comments | Shuai | last 3 s |

- Stories are original and everyday; verify every number (e.g. 1.01 to the 365th power ≈ 37.8)
- Avoid words the voices mispronounce; keep lines short — split anything over 6 s into two shots
- Topic bank: compound interest, inversion, green-light thinking, decluttering, probability, playing to your strengths, differentiated competition, end-game thinking, backups, sunk cost, Occam's razor…

## Step 2: script `scripts/zyNN.json`

Copy `scripts/zy01.json` and change `name` (`top-thinking_<model>`), `topic` and `shots[]`. Each shot:
- `refs`: characters on screen (`["Shuai"]`, `["Mei"]`, `["Shuai","Mei"]`; `[]` for story visuals) — use the character names exactly as they are defined in `zy01.json`
- `first` / `last`: first- / last-frame descriptions (the same scene sentence; the fixed set is `a peaceful riverside with a big willow tree on a sunny afternoon`)
- `motion`: **say who moves by describing their looks** (`the young woman with the high ponytail, round glasses and denim jacket ...`), and state that the other person stays still
- **When both are in frame, `last_edit` is mandatory**: again describe by looks "who does what, the other person stays exactly the same"
- `lines`: `[{"who": "Mei", "text": "..."}]`; `pause` adds silence after a line
- Voices are set per character in the JSON (e.g. `en-US-BrianNeural` for Shuai, `en-US-AvaNeural` for Mei)

## Step 3: generate

```bash
python tools/make_talk_mv.py scripts/zyNN.json --preview 3   # preview of the first 3 shots (about 10 minutes)
python tools/make_talk_mv.py scripts/zyNN.json               # everything (finished shots are skipped)
python tools/make_talk_mv.py scripts/zyNN.json --compose     # re-compose only (after subtitle / line changes)
```
`tools/make_talk_mv.py`: voice-over first (shot length is set by the dialogue) → FLUX draws the first / last frame (single character: reference the design image; **with both in frame, the last frame is an edit of the first**) → 5B first/last-frame video (frames = duration × 24, 33–89) → grading → trim the tail → interpolation to 60 fps → concatenate + top title (series name + the model's name in yellow) + subtitles ("Mei:" in blue, "Shuai:" in green, auto-wrapped) + loudness −16 LUFS.
Timing: about 2–5 minutes per shot (proportional to shot length; 89 frames take about 5 minutes); a 10-shot episode takes about 45 minutes.

## Known pitfalls (measured)

- **Faces bleeding between the two characters**: redrawing the last frame with both design images as references put Mei's face on Shuai → make the last frame an edit of the first frame as the only reference, describing people by their looks (`last_edit`)
- **The action goes to the wrong person**: `motion` said "Mei complains" and Shuai shrugged instead → describe by looks and add that the other person `stays still ... mouth closed`
- **Long subtitles got cut off**: now auto-wrapped (each line at most 86 % of the screen width, preferring to break at punctuation)

## Step 4: check and deliver

- Grab frames and go shot by shot: faces bleeding between the two? does the speaker match the action? subtitle colours and line breaks? garbled text in story visuals?
- Failed shots: delete `assets/zyNN/NN.mp4` (to redraw, also delete `keyframes/NN_a.png` and `NN_b.png`), adjust `motion` / `last_edit` and rerun
- Delivery: `open -a "QuickTime Player" works/zyNN_.../zyNN.mp4`; write `zyNN_post.txt` (title as a question; description + comment question + `#topthinking #mentalmodels #mindset #growth #AIanimation`; **tick "Content is AI-generated"**; say in the description that the story is fictional; collection "Top Thinking"; pick light instrumental music in the app at 15–20 %, never louder than the dialogue)
