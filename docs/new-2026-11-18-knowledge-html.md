## 开始创作 / Getting started

- 知识短片：先挑一个能用动作解释的具体问题，做最难的一镜，再扩展全片。 / Pick a concrete question, prototype the hardest explanatory shot, then expand the film.
- 互动 HTML：先打开作者实例，找到一个可变参数、一个可见结果，再改成自己的主题。 / Start with one editable parameter and one visible consequence.
- 制作依赖见各项目；GitHub 的 HTML 文件链接展示源码，不等于在线体验。 / See project dependencies. A GitHub HTML file link shows source, not a hosted demo.
- 媒体与源文件已核对，未运行上游创作流程。 / Source and media references checked; upstream production workflows were not executed.
