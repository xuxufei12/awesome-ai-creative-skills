# suntay44/motionable

The latest and updated Claude Code plugin that turns your app, website or project folder into a hype video. AI plans a beat-synced motion-graphics launch video, composes original music and renders a 9:16 MP4 for TikTok, Reels and Shorts. Free, open source, macOS-only Swift engine: nothing to install. Also works with Codex via Agent Skills.
