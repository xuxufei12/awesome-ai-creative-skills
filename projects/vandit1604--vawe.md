# Vandit1604/vawe

vawe is an open-source HTML to video framework for agent-native motion graphics: one HTML page in, one film out. It is programmatic video and motion graphics as code, a free alternative to Remotion, HyperFrames and Motion Canvas, built so that coding agents (Claude Code, Codex, Cursor) write the films. The page is plain HTML, CSS, Web Animations, SVG, canvas or three.js. The renderer seeks it frame by frame in Chrome, mixes its ` ` tags offline and encodes one deterministic mp4.
