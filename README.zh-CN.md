## 如何使用

1. 先看动图和图片，挑一个你想做的效果。
2. 点击卡片下方的「提示词」或「Skill」，查看正文、用法与所需素材。
3. 换成自己的主题，先做静帧或 5–10 秒小样，再制作完整作品。
4. 想继续找灵感，就打开视觉目录逐页浏览；需要特定工具时再查分类目录。
