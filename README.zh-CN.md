## 如何使用

1. 先按用途选项目，再打开对应的 Skill 或提示词。
2. 核对原始来源、许可证、依赖和输入素材；宿主标签只表示来源提及。
3. 先做静帧或 5–10 秒小样，再扩大到完整作品。
4. 作品效果属于上游作者；缺少公开正文、效果或复现证据的条目会明确说明。
