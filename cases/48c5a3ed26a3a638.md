# MusicKit 与 WebGPU 交互歌词播放器

作者借助 Opus 5.5 将早期手写的 GLSL 歌词着色器接入 MusicKit 播放器，并公开网页。作者说明经过多轮开发，网页版本不含本地演示中的音频反应与失真效果，后续又将部分 TSL 改回 GLSL。
