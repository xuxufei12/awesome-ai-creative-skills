# Swiss Motion → Material Grid / 从平面网格到立体材质

保留瑞士风格的网格、节拍和排版，将平面形状变成黏土、塑料、毛毡、玻璃与镀铬材质；俯视是海报，倾斜镜头后是立体物件。
