# 3500 条整数数列的交互式 3D 图谱

作者将整数数列的 weight、level 与 jump 分解绘成可切换的二维图与三维点云，并公开 Three.js 网页和工程；原帖注明使用 Claude Code 与 Opus 5.5。 作者后续将公开网页扩展至 5000 条数列，资源入口保留该更新的原帖。
