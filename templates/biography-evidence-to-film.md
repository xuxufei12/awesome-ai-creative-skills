# 人物传记：资料、转折与影像章节

**Original synthesis by this catalogue, not a quotation from GitHub or a tested result. / 本次原创整理，不是 GitHub 原文，也不是实测结果。**

````text
为【人物】制作约 3 分钟的人物传记。先用资料 Skill 整理生平时间线、关键作品、3 次命运转折与原文出处，明确争议和不确定信息。用一个有据可查的关键时刻开场，再交代背景。把每次转折写成处境、选择、代价和后续影响；原话必须可追溯，重构场景标为示意。用分镜 Skill 输出人物设定、镜头画面、解说词和首尾帧提示词。路线与时代空间可交给 code-doc-film；诗人作品章节可交给 code-poem-film。先选一种画面路线做 10 秒样片，再制作全片；不把静态画像的缩放当作全部叙事。
````
