# 代码 MV：让每段歌词发生一件事

**Original synthesis by this catalogue, not a quotation from GitHub or a tested result. / 本次原创整理，不是 GitHub 原文，也不是实测结果。**

````text
使用【选定的 MV Skill】，把我提供的 song.mp3 与 song.lrc 做成【像素 / 贴纸 / 手绘】叙事 MV。先核对音源版本与逐句时间，不凭节拍估算歌词起止。围绕歌曲建立一条人物行动与关系变化的主线，让重复副歌每次推进故事。每镜写清人物要做什么、发生什么变化、观众需要看多久；保持角色和空间一致。先做最难的 15 秒试片，检查动作、转场和歌词同步，再扩展全曲。交付 MP4、字幕、封面、场景代码和时间轴。歌曲音量与原文件对照检查，不额外添加旁白。
````
