# 知识图卡系列

**Original synthesis by this catalogue, not a quotation from GitHub or a tested result. / 本次原创整理，不是 GitHub 原文，也不是实测结果。**

````text
将【材料】做成 6 张 3:4 知识卡。第 1 张提出问题，第 2–5 张各解释一个要点，第 6 张总结。每张只承担一个主信息；所有数字必须可追溯到原材料。统一人物、色板、标题层级和页码。先给出每张的文本与布局，再制作图片；交付图片与可编辑文案，逐张检查中文文字和信息一致性。
````
