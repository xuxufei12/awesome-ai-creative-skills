# 角色一致性四镜

**Original synthesis by this catalogue, not a quotation from GitHub or a tested result. / 本次原创整理，不是 GitHub 原文，也不是实测结果。**

````text
为同一位原创角色【描述】设计角色参考表和四个镜头。先固定面部、发型、服装、标志物、比例与配色，给出正面、侧面和背面参考。四镜内容依次是【动作 1–4】，只改变镜头、动作和场景，不能改变身份特征。逐镜写出环境、景别、动作、光线和连续性约束；使用参考图作为后续生成条件，并列出不一致的细节供修正。
````
