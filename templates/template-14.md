# SVG 角色微动画

**Original synthesis by this catalogue, not a quotation from GitHub or a tested result. / 本次原创整理，不是 GitHub 原文，也不是实测结果。**

````text
用 SVG 为【角色】制作 5 秒无缝循环，包含呼吸、眨眼和一次招手。把身体、头、眼睛、手臂拆成可编辑分组，固定旋转支点，所有动作连续衔接。保持 viewBox、图层顺序和描边一致。交付 SVG 与离线 HTML 预览，检查循环接缝和不同尺寸下的显示效果。
````
