# Attribution & licenses / 来源与许可

This repository is an attributed research catalogue. It is not the original author of the collected Skills, prompts, example images, videos, fonts or tools.

本项目是带来源的研究资料目录，不是所收录 Skill、提示词、图片、视频、字体或工具的原作者。

- Each project, Skill, prompt and case has its own source links. GitHub sources are pinned to a commit where available. Identical text keeps all known attributions.
- Every media reference points to an upstream asset or viewer. No third-party videos are reuploaded here. A preview may be an input/reference image as well as a result; refer to the original section for the full pairing.
- Upstream code licenses do not necessarily cover prompts, generated media, reference images, trademarks, music or fonts. A missing license is not permission for commercial reuse.
- The supplied PDF is not republished. Its relevant text is transcribed with page references; typographic normalization is disclosed. The bibliography's claims and social-post attributions are not independent verification.
- This repository does not apply a blanket open-source license to third-party material. Only the original catalogue generator and validator in `scripts/` are covered by `LICENSE-CODE`.
- For a correction, attribution request or removal request, open an issue with the record URL and original source. Maintainers should prioritize preserving the source creator's wishes and provenance.

每条详情都有出处；重复正文会合并来源。上游代码许可证不一定覆盖示例图、提示词、商标、音乐和字体。未标注许可不等于可商用。需要纠错、补充署名或移除内容，请提交包含条目链接与原始来源的 Issue。
